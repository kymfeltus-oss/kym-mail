# Testing

Run `npm test` for Vitest unit tests. Current coverage verifies credential structure, environment failure behavior, safe error translation, sensitive logging redaction, Pub/Sub/OIDC validation, Gmail payload normalization and HTML sanitization, compose/attachment input rules, and per-type Project validation—including invalid names, missing fields, malformed versioned parameters, deduplication, and immutable type behavior. Run `npm run lint`, `npm run typecheck`, `npm run build`, and `npm audit` for static, production, and dependency checks.

Live verification requires the configured Supabase owner, Google OAuth test user, Gmail API, Pub/Sub topic and authenticated push subscription, verified sender aliases, and Vercel deployment. In addition to the Mail Core journey, Gate 3 verification creates every Project type against live Supabase, persists edits and lifecycle transitions, checks Archive/Restore, validates anonymous RLS denial and invalid inputs, opens shared Compose with and without Project context, sends a real Project-linked message, ingests a real reply, and confirms the thread/message/activity association. Verify desktop, tablet, and mobile routes with no fabricated records or metrics. Tests protect behavior and boundaries; they do not substitute for the required live journey.
